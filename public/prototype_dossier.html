3. 🧮 Core Mathematical Algorithms (Formulas & Logic)

Algorithm 1: Pod Fit Score Formula (Matching Engine)

PodFitScore = (0.40 × S_tech) + (0.25 × V_commit) + (0.20 × Q_test) + (0.15 × M_avail)
  • S_tech (40% Weight): Tech stack similarity between student skills and SME problem requirements.
  • V_commit (25% Weight): Git commit velocity and past task completion speed.
  • Q_test (20% Weight): Automated CI/CD test pass percentage on previous sprint submissions.
  • M_avail (15% Weight): Industry mentor review capacity and domain alignment.
🗣️ HOW TO EXPLAIN THE MATCHING FORMULA
"We don't match students randomly. Our algorithm calculates a 0-100% Fit Score based on 4 factors: 40% tech skills, 25% coding speed, 20% test quality, and 15% mentor bandwidth."

Algorithm 2: Cryptographic Skill Passport Signature (Fraud Defense)

SignatureHash = HMAC-SHA256( Key_Platform, StudentID || MentorID || SkillTag || CommitSHA || Timestamp )

Prevents resume fraud. Every skill verification issued by an industry mentor is sealed with a cryptographic hash. Anyone can scan the QR code to verify the authentic commit on GitHub.

Algorithm 3: Pod Health & Bottleneck Radar

HealthScore = 100 - [ (Days_Blocked × 12) + (Unreviewed_PRs × 8) + (Test_Failure_Rate × 0.5) ]

Monitors active pods in real time. If a pull request is blocked for more than 2 days, the health score drops below 70%, automatically notifying the mentor to unblock the students.

5. 🛡️ Jury Defense Cheat Sheet (Top 12 Questions & Answers)

Q1: How does SkillPods directly address SIH26044?
SkillPods is a complete Academia-Industry collaboration portal featuring automated skill mapping (Pod Fit Score), real industry internships/apprenticeships on SME problems, and cryptographically verified Skill Passports for campus placements.
Q2: What happens if an SME refuses to pay after students finish the project?
SMEs must deposit milestone funds into the Smart Escrow Vault before the sprint starts. Once the Industry Mentor approves the code and CI/CD tests pass ≥95%, the funds are automatically disbursed to students without requiring further SME approval.
Q3: How do you prevent students from submitting fake certificates or fake code?
All code must pass through AST static security analysis, unit test coverage gates, and manual code review by verified Industry Staff Mentors. Skill Passports are sealed with HMAC-SHA256 signatures tied to merged GitHub commit SHAs.
Q4: Why did you choose MongoDB Atlas instead of a purely relational database?
SkillPods handles deeply nested, dynamic documents including multidimensional skill passports, dynamic pull request contributions, and real-time audit event streams. MongoDB's WiredTiger snappy compression provides high write throughput and zero-downtime schema evolution.
Q5: How does this help colleges with NAAC and NIRF accreditations?
Our Institutional Dashboard includes a 1-click NAAC Exporter that compiles verified industry projects, student stipends, and mentor MOUs into official audit reports satisfying NAAC Criterion 3.5.1 (Industry linkages) and Criterion 5.2.1 (Student placements).
Q6: How does the system handle high traffic if 10,000 students log in at once?
The frontend is globally distributed on Cloudflare's edge network (sub-20ms latency). The backend is containerized in Docker and horizontally scalable, backed by MongoDB Atlas cloud replica sets.
Q7: How is chat privacy maintained between students, mentors, and SMEs?
Direct messages are private and end-to-end scoped between the sender and recipient. However, to prevent academic fraud or harassment, the SuperAdmin (sanketbhende0@gmail.com) has a protected global audit view (/api/admin/all-chats) for compliance oversight.
Q8: How does GURU AI prevent malicious prompt injections in the Voice PRD?
The voice transcription pipeline sanitizes all speech inputs, passes them through a structured JSON schema enforcement layer, and runs AST syntax validation before generating technical specifications.
