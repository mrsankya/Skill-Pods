1. 🎯 Objective & Problem Statement

Main Objective: To replace useless, throwaway college capstone projects with real-world SME problem solving, empowering students to build production software, earn milestone stipends in escrow, and graduate with verified cryptographic Skill Passports for campus placements.

Problem Statement Mapping:

  • Primary Match (SIH26044): "Portal for Academia - Industry collaboration for Skill Mapping, Internships and Placement" (Ministry of Ayush / Central Gov).
  • Secondary Match (SIH26043): "A digital platform to crowdsource societal challenges and facilitate collaborative problem solving through universities and industry partnerships".

The Core Problem it Solves:

  • For Students: Engineering students build dummy projects with no real users and graduate with unverified resumes that corporate recruiters cannot trust.
  • For Indian SMEs: Small businesses and startups have real software needs but cannot afford expensive dev agencies charging ₹5,00,000+ for basic MVPs.
  • The SkillPods Bridge: SMEs post real problems with money; students form 3-person teams to build solutions; industry mentors review the code; students get paid and receive cryptographic proof-of-work certificates.

6. 🛡️ Technical Challenges & Master Viva Defense (Cheat Sheet)

Q1: What are the main technical challenges in building SkillPods?
Answer: Three main challenges: (1) State Synchronization between student PRs, mentor approvals, and escrow releases; (2) Tamper-Proof Verification ensuring nobody can forge a Skill Passport; and (3) Low-Latency Telemetry for real-time collaboration. We solved these using HMAC-SHA256 signatures, sliding-window rate limiters, and Cloudflare edge caching.
Q2: How does the Smart Escrow Vault protect both SME and students?
Answer: SMEs deposit milestone funds into the escrow vault before work starts so students are guaranteed payment. However, funds are only released when the Industry Mentor signs off on the code quality. If students abandon the project, the SME gets a 100% refund.
Q3: How does the Skill Passport prevent fake resumes and credential fraud?
Answer: Every Skill Passport is sealed with an HMAC-SHA256 digital signature incorporating the student's ID, mentor ID, and the exact merged GitHub commit SHA. When recruiters scan the QR code, it verifies against the live tamper-proof record.
Q4: Why use MongoDB Atlas Cloud instead of PostgreSQL?
Answer: SkillPods manages deeply nested, dynamic documents—such as multi-skill passport stamps, fluctuating PR contributions, and real-time chat streams. MongoDB's document model with WiredTiger Snappy compression allows zero-downtime schema updates and high write throughput.
Q5: How can the system scale if 10,000+ students join?
Answer: The frontend is globally distributed across Cloudflare's edge network (sub-20ms latency). The backend is containerized in Docker for horizontal auto-scaling, backed by MongoDB Atlas cloud replica sets.
Q6: What are the security best practices implemented in this stack?
Answer: (1) PBKDF2 (SHA-512) password hashing with 32-byte salts; (2) Constant-time equality checks (`crypto.timingSafeEqual`) to stop timing attacks; (3) Recursive NoSQL operator stripping to prevent `$gt` injection; and (4) Sliding-window rate limiting.
